# Дневник студента

Программа для Windows: расписание, пропуски (с графиком), оценки, предметы, заметки и встроенный портал el.ncfu.ru.

## Скачать
Файл **[Dnevnik-studenta.exe](Dnevnik-studenta.exe)**: откройте его и нажмите кнопку скачивания (⬇, «Download raw file»). Установка не нужна, просто запустите.

Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

## Сборка из исходников
```
npm install
npm start          # запустить
npm run dist       # собрать .exe в папку dist
```
