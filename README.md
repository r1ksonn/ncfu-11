# Ecampus

Программа для Windows, чтобы следить за своей успеваемостью в СКФУ. При запуске вы входите в свой аккаунт на настоящем сайте eCampus (ecampus.ncfu.ru) прямо в окне программы: пароль вводится на сайте университета, программа его не видит и не хранит. После входа доступны вкладки **Ecampus**, **Мои курсы** (el.ncfu.ru) и личный дневник: расписание, пропуски с графиком, оценки, предметы, заметки.

## Скачать
Файл **[Ecampus.exe](Ecampus.exe)**: откройте его и нажмите кнопку скачивания (⬇, «Download raw file»). Установка не нужна, просто запустите.

Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

## Сборка из исходников
```
npm install
npm start          # запустить
npm run dist       # собрать .exe в папку dist
```
